# Ảnh chất liệu (textures)

Tất cả ảnh trong thư mục này lấy từ **Poly Haven** (https://polyhaven.com), giấy phép **CC0** (public domain, dùng tự do kể cả thương mại, không bắt buộc ghi nguồn). Đã thu nhỏ/nén lại để nhẹ cho web (ảnh màu 1K, pháp tuyến/độ nhám 512px).

| File | Nguồn Poly Haven | Dùng cho |
|------|------------------|----------|
| leafy_grass_* | leafy_grass | nền cỏ |
| forest_leaves_02_* | forest_leaves_02 | đất lá rừng |
| coast_sand_01_* | coast_sand_01 | bãi cát |
| damp_beach_sand_* | damp_beach_sand | cát ướt, đáy biển |
| mossy_rock_* | mossy_rock | vách đá trên địa hình |
| lichen_rock_* | lichen_rock | các hòn đá |
| pine_bark_*, bark_brown_02_*, palm_tree_bark_* | cùng tên | vỏ cây thông / cây gỗ / cây cọ |
| leaves_diff.jpg, leaves_alpha.jpg, leaves_nor.jpg | mô hình island_tree_02 (ảnh lá) | ghép thành ảnh cành lá cho tán cây |
| rusty_painted_metal_* | rusty_painted_metal | thép sơn chống gỉ của cầu |
| metal_plate_* | metal_plate | mặt cầu thép tấm |
| concrete_* | concrete | trụ và mố cầu |
| skin_wrinkle.jpg | mud_cracked_dry_03 (ảnh màu, chuyển xám) | nếp nhăn / vảy sừng trên da khủng long |

Lá kim, lá cọ, lá dương xỉ vẽ bằng code lúc chạy (client/src/render/pbr.js), không có file.
